# osk-openworld

## When to use
Use for `/osk research`, `/osk evolve`, `/osk verify`, OpenWorld source plans, anchors, verifier suites, refinement, reports, and promotion proposals.

## Workflow
1. Start with leakage checks and source planning.
2. Use Source Cards and Anchor Cards for provenance.
3. Run verifier quality and refinement before promotion.
4. Report proof level and next review action clearly.

## Safety
- Artifact-verifier success is not hidden-oracle benchmark proof.
- Do not read denied oracle paths or hidden benchmark answers.
