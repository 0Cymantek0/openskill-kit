# osk-review-gate

## When to use
Use for `/osk review`, behavior activation, rejection, edit, merge, split, workflow decisions, and OpenWorld promotion review.

## Workflow
1. Read the review queue and evidence cards.
2. Explain risk, confidence, and compile impact before action.
3. Apply only the requested review action.
4. Recommend `/osk compile` after accepted behavior changes.

## Safety
- Do not treat candidate skills or OpenWorld promotions as active behavior.
- Do not merge or activate conflicting behavior without explicit review.
