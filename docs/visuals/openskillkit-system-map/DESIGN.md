# OpenSkillKit System Map Visual Identity

## Style Prompt

Premium dark technical documentation animation. Solid charcoal background, thin
white outlines, precise grid layout, minimal teal/amber/red accents, no
gradients, no glow, no shadows, no decorative texture. Motion should reveal the
actual system flow and privacy boundary, not entertain.

## Colors

- Background: `#0b0f12`
- Text and rules: `#f8fafc`
- Muted text: `#b8c4cc`
- Data/content accent: `#4fd1c5`
- Review/decision accent: `#f6c453`
- Blocked/not shared accent: `#ff5a5f`

## Typography

- Primary: native system UI stack, heavy weights for section labels.
- Data: `Consolas`, monospaced labels for compact technical notes.

## What NOT to Do

- No gradients, glow, shadows, blur, 3D, or texture.
- No decorative elements without explanatory purpose.
- No unlabeled arrows.
- No invented claims beyond README and Learn v2 docs.
- No bounce, elastic, or playful easing; motion should feel precise and
  operational.
